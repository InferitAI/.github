This repository holds the profile of the [InferitAI](https://github.com/InferitAI) organization on GitHub. Inferit is a peer-to-peer market for AI inference: anyone can sell inference for any model, and buyers and agents pay per request.

| File | What it is |
|---|---|
| [`profile/README.md`](profile/README.md) | The page shown on [github.com/InferitAI](https://github.com/InferitAI) |
| `profile/inferit-lockup-2400w.png`, `profile/inferit-lockup-reverse-2400w.png` | The logo for light and dark themes, unchanged from the Inferit brand kit. Do not edit, recolour or redraw them |

To change the profile, edit `profile/README.md` and open a pull request. Links in it must resolve, and claims must match the [docs](https://inferit.cc/docs).

> **Status:** Testnet demo on Whitechain Sepolia. Prices settle in Inferit Test Credit (ITC), a test token with no monetary value. The contracts are not audited.
